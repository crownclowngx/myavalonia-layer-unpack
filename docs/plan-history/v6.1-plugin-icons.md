# V6.1 插件图标同步升级

日期：2026-09-11。插件版本：`1.0.0` → `1.0.1`。
本轮升级到 Core/UI SDK `3.4.0` 与 Plugin.Build `1.1.3`；最低 SDK 为 `3.4.0`，上界仍为 `4.0.0`。
V6.1 是本次改造顺序，插件版本独立维护。业务 ID、Group、入口顺序、命令及原有功能不变。

## 图标选择

公共八图标能够准确表达语义时直接引用 `CommonIcons.*.Key`；其余采用插件拥有的原创填充路径。
不新增 PNG、外部图片链接、字体包或 Host 业务图标枚举。新版树与功能中心显示以下图形，旧版目录仍使用 Host 默认图标。

| 入口 | 图标来源 | 语义 |
| --- | --- | --- |
| 解压任务 | 专属 `archive-unpack` | 归档盒与向外箭头 |
| 压缩任务 | 专属 `archive-pack` | 归档盒与向内箭头 |
| 浏览任务 | 公共 `CommonIcons.Folder` | 文件目录浏览 |

## 实现与边界

入口见 [真实 Module](../../src/LayerUnpackPlugin.Plugin/Plugin/LayerUnpackPluginModule.cs)。专属路径见 [PluginIcons](../../src/LayerUnpackPlugin.Plugin/Plugin/PluginIcons.cs)。

模块在 Configure 内调用 `AddIcon`，使用注册返回值填入 `IconPath`，不手写所有者前缀。
矢量数据为不可变值，逻辑画布 20×20，采用 EvenOdd 填充；颜色、缩放和缓存由使用位置及 Host 决定。
执行真实模块组合的独立预览与测试注册器已适配可选图标接口，以本次实例字典记录图形并拒绝重复名称；
预览不建立 Host 的全局注册表、可用性治理或缓存，业务页面仍使用原有实例。

显式引用 `MyAvaloniaManagement.Icons 1.0.0`，并声明 `ManagedPluginPrivatePackage`。
资源 DLL 随插件 ZIP 作为普通私有程序集部署；Core/UI SDK 仍由 Host 共享，不能混入插件 ZIP。
