# V1 本地候选说明

日期：2026-09-07。当前状态：已实现本地候选；未发布。

## 已实现

- 批量输入与目录扫描、深度 1–16、所有分支递归、TAR 组合格式一层语义。
- 同批次候选密码跨层、跨包共享，成功候选优先，补密后仅重试可恢复失败节点。
- 独立输出、同名编号、保留源包、取消回滚、部分失败诊断与资源预算。
- 真实 Document、Standalone Scope、关闭排空、结果树、编码选择和无历史记忆。
- 无 UI 类库、真实格式/故障/并发/生命周期测试，以及可复跑的本地检查脚本。

## 已知边界

RAR5 加密包已验证代表性样本的输出内容，但当前库不校验加密内容的 MAC；每个受影响节点显示提示，不承诺损坏检测完整。TAR 文件名要求 UTF-8；旧编码 TAR 会失败。旧 ZIP 名称可手动选择编码，ZipCrypto 密码按 UTF-8。完整变体证据见[支持矩阵](refactoring/G0003/format-support-matrix.md)。

分卷、SFX EXE、修复、ISO/CAB、密码破解、无限深度、CLI 和跨插件动作不在 V1 范围。现有预算约束实际展开工作量，不构成底层解码器的硬内存/CPU 沙箱；取消是协作取消，不能保证同步头解析/密钥派生立即中断。运行时进程意外终止可能留下 `.layer-unpack-*` 临时目录，正常取消和关闭会清理；没有自动接管旧残留或自动恢复历史。

本轮没有执行 Release、正式 ZIP、部署安装或真实 Host 发布验收，也没有新增 Windows CI 或使用 AIFLOW。操作系统原生文件/目录选择、真实拖放和 125%/150%/200% DPI 手工验收待实机检查；自动化已覆盖绑定、Tab 导航、明暗主题、尺寸变化和窗口关闭代码。

实际本地结果和发布前清单见[G0006 结果](refactoring/G0006/result.md)及[验收矩阵](refactoring/G0006/acceptance-matrix.md)。
