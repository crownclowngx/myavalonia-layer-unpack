# G0002 Headless 执行契约

本契约对应 `Headless/Contracts`、`UnpackService`、`PasswordPool` 和 `ExecutionBudget`，日期 2026-09-07。

## 输入与会话

`IUnpackService.CreateSession(UnpackRequest)` 返回隔离的 `UnpackSession`。请求复制输入和密码集合；输出必须为绝对目录路径，输入必须为绝对文件路径。创建会话检查参数、有限预算和输出祖先链接，但不创建输出；输入存在性在执行时复查。

输入路径按操作系统路径大小写规则去重，顺序保留；不按内容去重。批次 ID、节点 ID 与每次 Execute/Retry 的操作 ID 都独立生成。`ExecuteAsync` 每会话只能开始一次；`RetryAsync` 只接受本会话可恢复的失败节点。并发执行/重试即时拒绝，不排队隐藏第二次操作。

密码先尝试无密码，再按“本批次已成功候选、其他候选原顺序”尝试。空行忽略、完全相同去重、保留空格与大小写；每个候选最多 1024 字符、不支持换行，最多 64 个。失败、成功记录和新增候选不跨会话共享。请求密码不进入 JSON 或 ToString，结果/进度/错误不携带密码或引擎异常链。

## 默认预算与可配置范围

| 项目 | 默认 | 可配置范围 |
| --- | --- | --- |
| 解压深度 | 1 | 1–16，无无限值 |
| 候选数 | 用户提供 | 总共 64 个，固定上限 |
| 批次累计展开计量 | 10 GiB | 1 字节–1 TiB |
| 单文件展开量 | 2 GiB | 1 字节–1 TiB，不能高于批次预算 |
| 单输入文件 | 4 GiB | 1 字节–1 TiB |
| 条目数 | 100,000 | 1–1,000,000 |
| 归档节点数 | 1,000 | 1–10,000，包含达到深度的已发现节点 |
| 尝试数 | 2,048 | 1–100,000，无密码尝试也计数 |
| 单包时间 | 5 分钟 | 10 毫秒–1 小时，覆盖摘要、候选及提交后发现；后代另计 |

预算在重试中继续累计，不退款。中间 TAR 与最终条目均计入；失败尝试的展开量也计入。字节在写前扣减，写入故障可能保守多计一个数据块，因此 `TotalWrittenBytes` 是累计展开计量，不是最终磁盘文件大小。条目/节点/尝试超限检查可能把计数记到上限 +1，以说明拒绝的那次工作。

目录扫描另设 100,000 个待扫描/已检查项和最多 100 条诊断；默认最多加入 1,000 个包。批次预算限制实际工作量，不承诺底层解析器的硬内存上限。当前性能基线不等于 4 GiB 输入或 10 GiB 输出容量验收。

## 状态与失败范围

批次：`Ready / Running / Completed / PartialFailure / Failed / Cancelled`。取消中的 UI 文案是过渡反馈，直到核心任务退出才得到 Cancelled。

节点：`Queued → Probing → Extracting → Extracted`；可终止于 `Failed / Cancelled / DepthLimit / NotRun`。顶层为 1；目录不计层；DepthLimit 不解内部目录、不尝试密码。格式探测只读取固定 512 字节签名。

普通包失败继续独立项。路径逃逸、链接或预算耗尽停止整个批次，剩余排队项为 NotRun；取消时剩余项为 Cancelled。已提交父包保持 Extracted，子包失败单独记录。提交后发现中断附加父节点 Error，计入 `DiscoveryFailures` 和批次部分失败；不创建指向父包本身的假子包。

错误区分密码或加密内容损坏、不支持格式/压缩/加密、缺卷、不可用输入、输出错误、路径、预算、超时、编码、源内容变化及已隔离的未知错误。可判定事实保留，不把底层只能给出的歧义改写为确定密码错误。

## 输出与重试

单包写入 `.layer-unpack-{随机ID}`，文件采用 CreateNew。成功后用 Directory.Move 提交为包名目录；已占用时增加 `(1)` 等序号，以最终移动结果仲裁并发。只对本次返回的文件清单发现后代。保留源包、内层包和已提交产物。

失败清理只针对本事务未提交目录。清理失败附带准确残留路径并禁止该节点重试，不覆盖原错误。进程崩溃或强制终止可能留下残留；不自动扫描和接管历史临时目录。

重试不改变原深度、输出、编码或预算。保持节点 ID，SHA-256 复核原内容；内容变化必须新建会话。Windows 下源文件以只共享读句柄覆盖摘要与提取。路径/链接/编码/格式不支持、缺卷、内容改变或预算终止等不可恢复项不开放重试。`ArchiveNodeResult.CanRetry` 与 `UnpackResult.RetryBlocked` 是 UI 和调用方的判断入口，服务仍再次验证。

路径边界不等于针对其他进程持续恶意替换目录的文件系统沙箱；用户不应在执行中修改输出树。版本不承诺恢复链接、特殊设备、权限或所有归档时间戳。

## 进度、取消与释放

结果和进度是只读独立快照；进度大约每 100 ms 及状态变化时发送，不编造总百分比。观察者异常不能撤销已经提交的结果。

Execute/Retry 进入工作后取消返回 Cancelled；锁等待前取消、参数错误、无效重试或并发误用可能直接抛出异常。核心续体不依赖 UI；Dispose/DisposeAsync 幂等地取消并等待活动工作退出，再清空密码引用。托管字符串不承诺物理清零。

取消为协作取消；底层同步头解析和密码派生不能保证立即中断。实际写入退出延迟见[性能基线](../G0006/performance-baseline.md)。
