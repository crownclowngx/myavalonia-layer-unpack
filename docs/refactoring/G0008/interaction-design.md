# G0008 压缩任务交互专项

日期：2026-09-07。核心路径：添加 → 检查名称和位置 → 开始 → 打开输出。R02 不展示格式下拉、压缩算法、级别、密码或预算。

## 页面状态

| 状态 | 页面行为 |
| --- | --- |
| 空 | 添加文件／文件夹、拖放提示，主要开始动作不可用 |
| 准备 | 后台读取清单与摘要，显示当前项，可取消，参数禁用 |
| 就绪 | 文件数与源字节、建议名称／位置、开始；清单按需展开 |
| 写入／收尾 | 有总字节时显示进度，当前项和取消固定在底部 |
| 完成 | 结果区域位于输入表单之前，显示真实输出路径、字节、耗时和打开文件夹 |
| 失败／取消 | 原因、清理残留及下一步可见；清理退出后才恢复编辑 |

固定标题与底部操作，内容独立滚动。900×760 和 640×520 深浅主题均生成空、就绪、完成截图；窄窗口中打开结果与开始按钮有实际位置断言。

## 建议与清单

首个输入生成名称；目录保留完整目录名，文件去扩展名后建议 ZIP。所有输入处于同一直接父目录时建议该目录，多来源时要求选择。手动输入的名称或位置不会被之后添加覆盖；清空才恢复建议策略。

添加后能确定目标时先准备，展示来源到包内根映射。精确重复输入在列表去重，父子覆盖由 Headless 说明合并数量。同名根编号或合并尚未展示时，第一次开始先返回清单，下一次开始执行。普通默认任务不需要展开清单或额外确认。

删除输入或编辑目标使缓存计划失效。即使绑定或程序调用在忙碌期间改变参数，当前工作仍使用冻结请求；下一次执行核对缓存与新目标，不能把新名称写到旧位置。

## 生命周期与窗口适配

文件选择与拖放不自动创建 ZIP。选择器异步返回仅应用于原可编辑 Document；原生对话框异常转换为简短提示。结果按钮打开已经提交产物的父目录，不使用之后编辑的目标字段。

每次开始或准备都先清除上一轮结果。即使新名称在参数检查阶段失败，也不能显示上一 ZIP 的成功按钮；已有产物仍保留在磁盘。此回归与来源变化后重新准备一起测试。

Standalone 在同一窗口提供解压、压缩两个标签，各自拥有 Scope 与 ClosingToken。切换不销毁任务；首次关闭先取消两类工作、等待真实退出，再释放 Scope 和关闭。原有同步 Scope 释放路径继续由不依赖 UI 的后台排空支持。
