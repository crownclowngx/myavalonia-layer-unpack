# G0008 执行计划：R02 基础 ZIP 压缩

日期：2026-09-07。状态：G0008-01–05 已实施，本地门禁通过；原生人工待验收，发布门禁未执行。前置：G0007 / R01 已实施并通过本地检查，原生人工与发布遗留仍单独记录。

## 目标与范围

在同一插件提供简洁压缩任务，把文件和文件夹合成一个普通 ZIP；复用同一 Headless 用例。默认 UTF-8 名称、标准 Deflate、无密码。用户添加输入、检查名称位置、开始并访问结果。

遵循 SOLID，以扫描计划、单包写入、文件事务、任务呈现分责。窄接口仅用于真实变化和故障替换；中文注释说明输入快照、预算、取消和提交理由。此次不实现 R03 的分组／加密，不改已有解压规则，不使用 AIFLOW、Windows CI、Release、正式插件 ZIP、部署或发布门禁。

## 核心规则

- 输入快照先规范化，父目录覆盖其已选子项；同名根按稳定顺序编号。预览提供来源到根条目的映射。
- 包内保留选中顶层目录、文件及空目录；拒绝链接和不符合现有 Windows 路径规则的条目。
- 请求输出路径和本事务临时文件不纳入输入；显式将输出文件作为源输入时拒绝。源目录内部的新输出子目录需先创建或改选已有目录，避免准备阶段落盘或无说明改变源树。
- 来源文件以长度、时间戳与内容摘要形成快照；执行前后核对清单、写入时核对摘要。不是整个文件系统的原子快照。
- 输出目录在写入时创建，临时文件在相同文件系统，归档收尾成功后移动提交；已存在目标按编号重试，不覆盖。
- 独立限制源字节、单文件、条目、输入项、目录深度、归档字节和时间。默认只开放产品必要字段。
- 页面关闭排空后台工作，不等待依赖 UI 的命令续体；取消完成后才能显示终态，迟到进度不能覆盖结果。
