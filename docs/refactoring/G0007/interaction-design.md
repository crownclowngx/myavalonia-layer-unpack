# G0007 交互专项：默认即可开始

## 默认流程

普通任务只需要添加文件、检查可见输出位置并开始。同一目录的输入建议其旁的“解压结果”；多来源需选择输出。默认一层，不要求填写密码、编码或资源参数。

| 状态 | 默认可见 | 按需出现 |
| --- | --- | --- |
| 空状态 | 拖放区域、添加压缩包、扫描文件夹 | 无配置表单 |
| 待开始 | 输入数量、添加入口、输出位置、递归开关、开始 | 输入清单、总层数、候选密码、旧 ZIP 编码 |
| 扫描／解压 | 当前状态、当前包和层级、取消 | 已发现结果与完整树 |
| 完成 | 结果摘要、打开结果、开始新批次 | 完整树、节点详情、下一批参数 |
| 部分失败 | 成功入口、非零失败统计、问题项 | 点击问题后补密／重试／调整选项 |
| 已取消 | 取消与未执行统计、已提交产物 | 清理问题与详细树 |

结果位于参数区前面。运行期间不修改本次参数；普通成功摘要不展示“失败 0”等计数。按深度停止属于正常结果，有实际停止节点时在摘要说明。

## 入口迁移

| 原入口 | 当前入口 | 保留语义 |
| --- | --- | --- |
| 常驻输入列 | “查看输入清单” | 去重、逐项选择与移除 |
| 常驻深度 | 递归开关与总层数 | 总层数含外层、目录不计层、组合归档计一层 |
| 候选密码区 | “密码（可选）”及详情“补充密码” | 一行一个、64 个上限、批次共享、明文编辑提示 |
| 常驻编码 | “更多选项” | GB18030／UTF-8／CP437／CP866，修改用于新批次 |
| 常驻结果树 | “查看完整处理树” | 稳定节点、父子关系、按需选择 |
| 常驻详情列 | 问题项或树节点选中后的详情 | 来源、层级、格式、原因、输出及清理残留 |
| 选中后打开目录 | 底部“打开结果”和详情“打开此项目录” | 直接访问批次产物或指定节点 |
| 开始／重试 | “开始解压”“开始新批次”“重试所选失败项” | 新会话与原会话恢复不混淆 |

## 窄窗口与键盘

单列内容 ScrollViewer 配固定底部操作，消除原三列对宽度的依赖。Standalone 最小 640×520；长路径在详情换行，在输入框可滚动检查。问题清单和树有最大高度，页面仍能滚动到设置。

展开密码后等待布局再 BringIntoView 和 Focus，且检查仍为原 Document。输出框可 Tab 到下一控件；递归开关可用空格切换，均有真实键盘测试。

自动图像覆盖深浅主题与 1180×760、1000×600、900×760、800×600、640×520 的适用组合，并非全排列。调整 Headless 窗口尺寸不等于原生 DPI 验证。

## 原生记录与待验收项

本轮通过 computer-use / `@oai/sky` 启动 Debug Standalone，观察实际空状态与中文控件，确认“添加压缩包”弹出原生选择器、Escape 取消、主窗最大化和关闭。关闭后再次枚举，已无该应用窗口。
