## 增加的边界场景

- 多来源清空自动建议；移除不同来源后恢复；显式确认相同路径后不再覆盖。
- 手动清空输出不能开始；清空批次重置选择、层数和展开状态。
- 隐藏 NumericUpDown 不改变默认一层；实际 CheckBox 空格操作正确映射 1 与 2。
- 修改下一批输出、编码、层数后补密重试，仍使用原批次参数。
- 编码失败不能原地重试；新批次导航不提前执行或丢失原结果。
- 认证受限提示进入问题列表，不因树折叠而隐藏。
- 取消后禁用再次取消，实际工作尚未退出时不显示完成。
