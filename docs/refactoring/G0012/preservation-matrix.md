# G0012 内容、元数据与格式保留矩阵

## 保留与限制

| 对象 | 普通格式转换 | 展开整理／结果打包 |
| --- | --- | --- |
| 普通文件正文 | 完整读取后保留；目标按长度和 SHA-256 回读核对 | 按规则预期清单保留；结果来源变化拒绝 |
| 相对路径、Unicode | 保留已支持读取的相对路径；使用 UTF-8 写 ZIP | R05 映射决定路径；合成按来源，分别用 ZIP 名表达来源 |
| 空目录、零字节文件 | 保留；隐含父目录可以成为显式 ZIP 目录项 | All 保留；筛选仅保留匹配文件及父目录 |
| 完全空包 | 生成真实空 ZIP | 没有匹配文件时跳过；明确的空结果分别包可为空 |
| 内部 ZIP/RAR | 按普通文件保留，字节不变；不探测或递归 | 只展开可见层数内分支，类型规则决定是否保留内部原包 |
| 原归档修改／创建时间 | 不保留原归档元数据；暂存文件时间可能进入目标 | 当前结果文件的修改时间映射到 ZIP DOS 时间，精度 2 秒，1980–2107 范围；不承诺原归档时间 |
| 权限、属主、ACL、扩展属性 | 不保留 | 不保留 |
| 注释、额外头字段、格式私有元数据 | 不保留 | 不保留 |
| 链接／设备／FIFO／套接字 | 已公开的特殊条目明确拒绝，不降格为空文件 | 沿用安全来源限制；文件系统链接／重解析点拒绝 |
| 来源认证状态 | 原有错误或限制原样传递 | 整理和打包结果继续传递，目标回读不提升来源可信度 |

不承诺完全无损转换。目标内容对照以文件路径／摘要及空目录为依据，不能用 ZIP 总条目数判定一模一样；隐含父目录的显式化会改变目录项数量。内容整理则使用规则预期清单，不能拿原归档总文件数作为成功条件。

## 格式证据

| 来源／目标 | R06 验证方式与声明 |
| --- | --- |
| RAR4、RAR5、固实 RAR | 真实公开夹具 → 新 ZIP → 独立 .NET 读取器逐路径 SHA-256 与公开原文摘要比较 |
| RAR4 加密正文／加密头 | 真实 `test` 夹具；正确候选转换和摘要核对 |
| RAR5 加密正文／加密头 | 能解码、内容摘要匹配；明确保留加密校验未验证提示，受限完成 |
| 7z LZMA、固实、LZMA/LZMA2 AES | 真实公开夹具，含错误候选后成功和目标独立回读 |
| ZIP、嵌套 ZIP | 中文、空目录、空文件、内部包字节一致；普通模式不发现内层；显式多分支深度 1/2/3 与 R05 预期映射对照 |
| TAR／GZip／BZip2／XZ | 使用原有已支持读取适配器；保留既有真实格式全量回归。本期特殊 TAR 类型另有拒绝测试，未把新格式变体扩张为“全支持” |
| ZIP 普通目标 | .NET 写入、SharpZipLib 提交前回读；测试另外用 .NET 解码与外部预期摘要对照 |
| ZIP AES-256 目标 | SharpZipLib 写入与提交前回读；已有解压适配器及 R03 独立读取器回归验证；来源密码 A 不能打开目标 B |

来源密码、分卷、旧编码、损坏和引擎能力仍受 [G0003 矩阵](../G0003/format-support-matrix.md)约束；不是通过更名、外部命令或独立新引擎实现。目标创建偏好沿用 [G0009 矩阵](../G0009/encryption-and-compression-matrix.md)，不新增依赖，不创建 RAR、7z 或覆盖原包。
