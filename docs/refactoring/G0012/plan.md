# G0012 / R06 格式转换与重新打包计划

日期：2026-09-08。对应 [R06](../../roadmap/R06-conversion-and-repack.md)，前置 R02–R05 已有源码和本地证据。最终状态以[结果](result.md)为准。

用户要求实现路线图内容；SOLID 优先、朴素设计、详细中文注释、单元测试和本地门禁齐全、同步专用文档。不使用 AIFLOW，不新增或运行 Windows CI，不运行 Release、正式插件打包、部署或发布门禁。

## 工作项与完成标准

| 工作项 | 实现与验证出口 |
| --- | --- |
| G0012-01 普通转换 | 一个来源一个新 ZIP；不探测内嵌归档；文件、路径、空目录及空包保留；真实 RAR/7z 独立摘要核对 |
| G0012-02 有限复合操作 | 明确选择展开层数和 R05 规则；复用原递归调度与整理映射；任一应执行分支失败时该来源不生成残缺 ZIP |
| G0012-03 结果打包 | 解压／整理提交清单可检查；合成或分别；来源变化拒绝旧计划，不能扫描接纳历史文件 |
| G0012-04 秘密与可信度 | 来源候选与目标秘密分开；默认目标明文；目标回读通过不抹去 RAR5 加密来源校验限制 |
| G0012-05 资源与事务 | 整项共享写入、解压条目／尝试和写包条目账本；每 ZIP 回读后提交；取消排空与残留报告 |
| G0012-06 页面衔接 | 解压输入“转换为 ZIP”；解压／整理结果“打包结果”；进入不执行；父任务关闭排空 |
| G0012-07 开发期验收 | 两个测试项目全量、零跳过、Debug 零警告、锁定还原、格式、文档链接与差异检查；真实内容与界面渲染证据 |

## 设计取舍

只新增有限用例和一个上下文子页，不引入流程图引擎、通用执行框架或第四个顶级 Document。普通转换使用暂存；整理后打包直接适配已验证映射，不多复制一份整理目录。默认不保留中间产物，本期不提供保留选项。

独立结果打包先预览再开始。转换需实际读取来源才能确定内容，开始后在任务内形成并执行清单；开始前明确显示模式、总层数、规则、输出位置及元数据限制。原生选择器、真实 DPI／Host 与发布留待对应环境验收，不用 Headless 图像代替。
