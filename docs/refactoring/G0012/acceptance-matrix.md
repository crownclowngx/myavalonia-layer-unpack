## 额外回归

`RepackSafetyTests` 覆盖解压字节、条目、尝试在多来源之间累计，以及 ZIP 写入条目／总写入上限、并发不覆盖、秘密开关矛盾和隐式规则拒绝。故障写入器产生遗漏或篡改内容时，真实提交前回读拒绝。

`ResultRepackTests` 覆盖既有用户结果不清理、按源独立失败、准备阶段不写目录、清单缺失／来源边界不全、旧整理结果只能合成。`RepackDocumentTests` 覆盖三个导航入口、预览失效、秘密隔离、取消／同步父 Scope 关闭、迟到回调、分页和两主题两尺寸渲染。

## 开发期与人工边界

执行 `tools/verify-local.ps1`：锁定还原、Debug 零警告构建、仅 Debug 引用资产求值、两个测试项目全量及 TRX 非零／无跳过检查、格式、文档路径、差异空白。所有结果通过后再归档，不用历史 347 项测试作为当前新增功能证据。

原生目录选择、系统辅助功能、125%/150%/200% DPI、真实 Host 是待实机项。Windows CI、Release、正式插件 ZIP、部署安装和发布门禁未执行；本阶段的普通 ZIP 数据产物测试不等于正式插件发布打包。
