# G0012 页面衔接与交互

## 三个进入位置

1. 解压任务添加来源后，“转换为 ZIP…”进入转换子页。来源列表冻结，默认普通转换；确认目标位置后点击“开始转换”。按需展开总层数、类型／包装链、旧 ZIP 编码和来源密码。
2. 解压操作退出且有提交结果时，“打包结果”带入当前结果。先“检查带入清单”，逐页检查映射后“开始打包”；默认合成，可选按来源分别。
3. 整理成功后，“打包结果”带入整理结果及其来源边界。预览不会重新扫描接纳历史文件，页面进入不创建新 ZIP。

解压、压缩、浏览三个顶级 Document 及其 ID 保持不变。SDK 当前没有携带任意快照的新建 Document 导航端口，沿用原浏览／整理上下文子页方式；Standalone 和 Host 使用同一真实 View/Document。浏览内承载的“全部解压”页自然具有这些入口；单独浏览选择提取结果本期没有直接重打包入口。

## 状态与秘密

转换页面持续显示普通转换与内容结构转换的区别、总层数和类型规则。原归档元数据不保留、默认目标不加密、中间内容归本任务并会清理，在开始前可见。类型筛选按扩展名，不做正文识别。

来源候选密码和目标密码分开显示，默认遮蔽；目标需输入两次并精确一致。导航不继承父页密码。字段不序列化，开始后立即清空，后台所有权在调用退出时释放。

预览显示精确包内路径，100 行分页可到末页，来源受限提示在对应组头中保留。输出位置、分组或目标加密开关变化使预览失效；后台捕获的原参数不随表单程序化变化而改变。完成／失败后旧计划失效，重新检查才能打包。

状态区固定在底部，显示当前来源、阶段和累计写入；首个错误或来源限制同步显示在状态区，详细来源→实际产物映射可滚动检查。执行退出后收起选项，当前子任务中此前成功 ZIP 路径保留。“打开 ZIP 所在目录”锚定最近实际提交产物，不使用可为下次任务修改的输出框。成功数不包含失败或跳过，受限来源单独计数；不承诺体积下降。

## 生命周期

运行时冻结输入和规则，并禁用返回父任务。取消按钮请求停止，等待写入和清理完成后恢复编辑。返回只切换视图；父解压新批次／重试／清空释放旧子页，父整理重新预览／执行释放旧打包页；关闭从父令牌取消并排空后台。成功磁盘产物不受导航和释放影响。

世代号与关闭状态过滤旧进度。同步 Scope 释放只等待后台 Task，避免等待 UI 命令续体。测试覆盖直接转换和整理结果子页中的取消、同步父 Scope 关闭及另一 Scope 隔离。

## 视觉证据范围

自动渲染覆盖浅／深主题、640×520 与 900×760、准备、选项、成功、结果预览及来源变化；固定主要操作可见并验证 Tab 焦点移动。这是 Avalonia Headless 平台证据，原生目录选择器、实际 Host、系统辅助功能及真实 DPI 仍须实机验收。
