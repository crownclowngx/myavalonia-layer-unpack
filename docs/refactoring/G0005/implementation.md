# G0005 实施方案：Document 完整交互

日期：2026-09-07。本文描述最终方案；历史模板和中途方案不作为现行实现。

## 最终行为

接入添加、目录扫描、拖放、移除、参数、明文候选、开始、取消、重试和打开输出。显示父子树、终态和诊断，运行时编辑受控，关闭后拒绝迟到回调。

## 职责与设计理由

View 只适配窗口能力；Document 管理 UI 命令、快照和运行代次，业务规则委托 Headless。两个 Document 共享无状态服务也不会共享会话。

公共参数和错误以[执行契约](../G0002/execution-contract.md)为准，不能在 UI 再定义一套深度、密码或重试规则。状态只保留在当前会话；生命周期结束释放密码引用和活动工作。

## 验证方法

DocumentTests、ViewTests、WindowLifecycleTests 覆盖真实业务一致性、补密、参数、两个 Document、同步释放、Tab、明暗和尺寸渲染。 整仓门禁通过统一脚本执行，命令、环境及数量见[G0006 结果](../G0006/result.md)，避免每个阶段复制一份易过时的测试统计。
