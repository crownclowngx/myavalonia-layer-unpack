# G0006 本地性能与资源基线

日期：2026-09-07。本表来自最终统一门禁，原始 JSON 在 `artifacts/performance`，本次快照保存在 [verification-summary.json](verification-summary.json)，测试定义为 `PerformanceTests.cs`。

## 环境与方法

Windows 11 家庭中文版 64 位，10.0.26200；Intel Core Ultra 5 225H，14 核 / 14 逻辑处理器；物理内存 33,752,997,888 字节；YMTC PC411-1TB-D 固态盘。输入和输出均为 C: 用户临时目录下的测试专属目录，未隔离其他进程的磁盘活动。仓库在 D:，结果不代表独立磁盘吞吐基准。

.NET SDK 10.0.302 / runtime 10.0.10，net10.0 Debug；SharpCompress 0.50.4、SharpZipLib 1.4.2。性能集合禁止与其他测试并行，固定生成内容，无用户私人样本。

| 样本 | 方法 | 本次值 |
| --- | --- | --- |
| 单个 64 MiB 文件 | 在计时前创建 ZIP；计时覆盖会话执行，随后独立 SHA-256 验证 | 输入 862,908 字节，展开 67,108,864 字节；241.2942 ms；托管累计分配差值 611,200 字节 |
| 2,000 个 1 KiB 文件 | 从执行到输出计数结束；随后连续 10 批次验证释放和无临时残留 | 展开 2,048,000 字节；2,571.9869 ms；十批次与独占打开检查通过 |
| 16 层嵌套 | 执行 16 个包，第 17 层按深度停止 | 成功 16、按深度停止 1；累计展开 81,944 字节；223.7390 ms |
| 128 MiB 文件写入取消 | 首次有实际写入的节流进度触发取消；计到会话返回且临时目录清理完成 | 取消前计量 30,539,776 字节；取消延迟 4.6253 ms；未提交内容清理完成 |

大文件及多文件测试记录到的测试进程峰值工作集均为 188,825,600 字节（约 180.1 MiB）。四项均通过内容、计数、停止或清理断言；本次具体数值不作为脆弱的逐毫秒门禁，取消测试仅对该样本设置 3 秒退出上界。

## 如何解释数值

大文件记录的进程峰值工作集属于整个测试进程，不是单次解压独占内存；分配量是累计托管分配差值，不是存活堆峰值。2,000 文件耗时不包含后续十批次的时间；连续批次以内容、输出数量与源文件可独占打开验证。

取消延迟只代表此 ZIP 样本的协作取消表现。第三方解码器在单次同步工作期间可能延迟响应，进程内预算不能强制限制解码器内存 / CPU；不承诺任意恶意归档均在该延迟内退出。强制隔离需后续进程工作器设计。

当前数值用于开发回归，不作为所有机器的性能 SLA，也不构成 4 GiB 输入上限已满载实测的承诺。固定默认预算与参数上限见[执行契约](../G0002/execution-contract.md)。
