## 可复现真实样本

运行 `OrganizationPerformanceTests` 或完整本地门禁，生成 `artifacts/G0011/acceptance-sample/甲/课程.zip`、`乙/课程.zip` 和 `expected.json`。样本含同名来源、嵌套 ZIP、连续包装链、同层 TXT、中文名称与空目录。深度 2 解压，整理规则为 PDF + 显式压平，预期 2,002 文件、两个独立来源；expected 文件保存精确目标清单、长度及 SHA-256。

指标位于 `artifacts/performance/G0011/organization.json` 和 `ui-paging.json`，最终数值见[结果](result.md)与[验证摘要](verification-summary.json)。样本完全由测试本地生成，无私人数据、网络下载或外部依赖。

## 本地与待验收边界

本地检查按 `tools/verify-local.ps1` 全量运行，不能以仅筛选的新测试替代回归。TRX 要求非零、全部通过、零跳过；格式、文档路径和差异检查也需通过。人工交互与真实 Host 待验收见[交互专项](interaction-design.md)。Windows CI、Release、正式包、部署安装与发布门禁不属于本次执行范围。
