# G0011：整理结果交互与生命周期

## 入口与默认界面

完成或部分完成一批解压后，结果摘要处出现“整理结果”，只有至少一个已提交节点且解压操作退出时可执行。不自动创建预览或整理目录。打开后是当前解压 Document 的临时子页，顶部可返回解压结果，不增加常驻工具面板或第四类顶级 Document。

默认可见：当前批次来源摘要、输出位置、“文件类型与目录层级”折叠入口、状态与“生成预览”。默认全部文件、不去包装层；无需展开选项即可完成普通整理。类型和压平在一次展开后可选择，扩展名说明明确可见。预览展示文件数、字节、来源、命名调整数、精确输出路径，以及前十个包装层变化摘要；完整变化通过映射查看。

映射按 100 行分页。可切换“只看命名调整”，所有详情仍可逐页查看。内容区域滚动，状态及执行操作固定页底，主要动作在预览就绪后为“开始整理”；无匹配内容明确说明并禁用执行。

## 代表场景

| 场景 | 用户决策与状态 |
| --- | --- |
| 普通全文件 | 整理结果 → 核对位置 → 生成预览 → 开始整理 → 打开整理目录，无需展开设置 |
| 多来源 PDF | 展开规则选择“仅 PDF” → 预览摘要与来源冲突 → 按需翻页 → 开始整理；各来源独立目录 |
| 连续包装目录 | 显式勾选压平 → 预览 RemovedPrefix 对应说明与目标映射 → 执行；同层额外文件会阻止继续压平 |
| 来源变化 | 拒绝执行，旧计划失效，显示具体路径并要求重新解压与预览；返回原结果仍可查看已有产物 |
| 目标被占用 | 清理本次未提交内容，要求重新生成预览，不覆盖、不偷偷改变已确认名称 |
| 取消/写入失败 | 等待真实复制及清理退出；显示取消或原因，清理失败展示所属残留绝对路径 |

运行冻结规则、输出与父页动作，取消后等待退出。关闭不持久化任务和清单。返回原页保留整理结果；新批次、重试或清空释放旧子任务，磁盘上已提交目录保留。两个父 Scope 的状态、取消与生命周期独立。

## 交互证据范围

自动化验证深浅主题、640×520 与 900×760，包含准备、映射预览、成功、来源变化四种状态；主按钮与成功入口边界、绑定、Tab 焦点都有断言。图片归档到 `artifacts/ui/G0011/`。1,200 文件分页与 UI 调度耗时写入 `artifacts/performance/G0011/ui-paging.json`。

这些是 Avalonia Headless 平台真实 View 渲染与生命周期验证。原生目录选择器、真实系统打开目录、125%/150%/200% DPI、辅助功能和真实 Host 仍待实机验收，不能由渲染测试代替。
