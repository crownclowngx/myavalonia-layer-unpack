## 样本、资源与界面

真实复杂样本含两个同名来源、内层 ZIP、中文路径、包装链、同层 TXT 和空目录，深度 2 解压后选择 PDF 并压平，得到 **2,002 文件、2,008 个映射、2 个来源、128,024 字节**。逐项摘要一致，样本与期望清单保留在 `artifacts/G0011/acceptance-sample/`。

最终完整门禁中，规划约 5,675.56 ms，执行约 15,760.77 ms；测量区间累计分配 65,514,136 字节，测试进程峰值工作集 169,496,576 字节。验证包含多次来源摘要与目标摘要，不能当作裸文件复制速度。首次独立样本累计分配约 1.40 GB，排查后关闭 FileStream 的重复内部缓冲，哈希与复制保留租用缓冲；最终累计分配明显降低。两次运行的进程环境与耗时不能作为严格对照基准。

1,200 文件的页面预览按 100 行分页，尾页可达；预览期间 UI 投递回调约 0.36 ms，全部翻页操作约 0.94 ms。这只记录本机样本调度与分页成本，不承诺任意文件规模下的时延。原始指标为 `artifacts/performance/G0011/organization.json` 与 `ui-paging.json`。

16 张视图渲染图位于 `artifacts/ui/G0011/`，覆盖两种主题、640×520/900×760、准备/预览/成功/来源变化。实际检查了浅色窄窗口预览、深色窄窗口来源变化和浅色大窗口成功图；主要操作、结果入口可见，长内容可滚动，命令与键盘焦点有测试断言。这些是 Headless 平台渲染，不是原生桌面或 DPI 验收。

## 范围与遗留

输入限当前 `UnpackResult` 的明确提交清单，支持其中已提交的部分成功内容；不补扫历史或任意目录。浏览中的“全部解压”承载的真实解压任务也能进入整理，单独浏览提取结果未新增整理入口。整理是父解压任务的临时子页，不新增常驻工具面板、第四类顶级 Document、Workflow 或自动重打包。

原解压拒绝同包内重复及大小写别名，当前真实冲突验收主要覆盖跨来源与已有目标。文件系统检查沿用既有路径与重解析点政策，不声称实现内核快照或敌对进程隔离；相同内容和全部凭据的替换不能被识别为不同文件系统对象。具体规则见[整理契约](organization-contract.md)。

原生选择器、系统打开目录、125%/150%/200% DPI、辅助功能与真实 Host 仍待实机验收。本期没有使用 AIFLOW，未运行 Windows CI、Release、正式插件 ZIP、部署安装或发布门禁。
