# R07 检查任务与格式选择交互

## 普通创建

默认依旧 ZIP、标准压缩、合成一个包。格式选择为一个轻量下拉框；输入、名称、目标、开始动作可直接访问。TAR 固定仅打包，TAR.GZ 可在原“更多选项”中调标准／快速／高压缩；不展示不可用的密码与 TAR 压缩级别。格式说明就地说明无密码原因。分别与排除仍沿用原入口，切换格式使旧预览失效。

## 按需检查

解压页添加来源后可点击“检查压缩包…”，检查子页从本批次来源选择一个包；浏览页也有同名入口，即使当前格式不能列目录仍可进入完整检查。只带来源，不继承原页密码或输出目录，不自动执行。

默认完整检查；可显式勾选“仅检查目录（当前支持 ZIP，不检查正文）”。密码与旧编码展开后填写，完整检查按需读取全部内容并使用临时空间。页面显示明确来源、“开始检查”和执行时的取消；没有虚构进度百分比或完成时间。

## 结果与恢复

目录成功显示“目录可读，尚未检查内容”；正文通过列出实际校验类型及文件数；RAR5 MAC 等限制显示“内容已读完，校验存在限制”。失败显示原因及下一步，不确定密码／损坏、缺卷／损坏时原样保留歧义。取消等待真正退出，残留路径单独显示。

运行中冻结编辑和返回。返回保留原解压结果或浏览目录选择；重新进入创建新的检查任务，密码不继承。父页关闭取消并排空子任务实际工作，迟到进度按代次过滤。关闭不等 UI 命令续体，以兼容同步 Scope 释放。

## 本地验证与人工边界

真实视图测试覆盖来源／格式绑定、默认值、切换格式清密、主动作、返回及原状态保留；检查页在 460×560 深浅主题和 900×720 渲染，键盘及主动作位置有断言。自动图片存于 `artifacts/ui/r07-check-*.png`，结果文档记录实际检查情况。

原生文件选择器、系统拖放、辅助功能、125%/150%/200% DPI、真实 Host 保留人工验收；没有将 Headless 图片当作这些项目通过。
