# G0015 验收矩阵与本地门禁

日期：2026-09-19。状态：**计划要求／全部功能场景待执行**。本文件不表示已经新增测试或具备分卷能力。本轮文档检查事实另见[结果记录](result.md)。

## 1. 真实样本和证据规则

以用户场景“外层 ZIP → 同目录 7z 多卷 → 实际文件”为首要验收样本，同时覆盖顶层直接添加分卷。使用独立 7-Zip 工具生成普通、固实、内容加密及头部加密样本，或选取固定上游版本、许可证清楚的夹具；不使用本项目未通过的 7z Writer 作为唯一来源。

记录生成工具版本、生成命令、每卷名称／长度／SHA-256、原始文件预期目录与内容摘要、公开测试密码和许可。对独立工具与本项目解出的结果逐路径、空目录和 SHA-256 比较；可执行样本只校验字节，绝不执行。所有密码均为合成测试数据，私人包不提交到仓库。

至少保留一轮独立工具互操作证据，日常回归可使用该轮生成并冻结的合法夹具。外部工具仅用于开发期生成／核对，不因此成为生产运行时依赖。缺少样本或测试工具时如实记为未执行，不伪造成功或通过跳过制造绿色门禁。

## 5. 本地门禁

实施时执行仓库现有入口：

```powershell
./tools/verify-local.ps1
```

编写时该脚本包含官方源隔离缓存的 locked restore、Debug 零警告构建、Debug 私有引用资产求值、Headless／Plugin／Workflow 集成／相邻 Studio 四组测试、格式互操作、代码格式、Markdown 链接和差异空白检查。分卷真实回归应加入已有项目，并把需要的独立互操作纳入本地取证流程；不另建只有新测试的“替代门禁”。

每组 TRX 要求非零、全部通过、零跳过。不能用 `--no-build` 读取旧二进制冒充新源码通过。相邻项目或独立工具不可用时记录缺失并保持门禁未完成，不跳过后宣称全绿；现有测试型 ALC／Studio 集成是开发期回归，不等于真实宿主安装发布验收。

结果记录实际命令、环境、基线提交、受测源码摘要、新旧测试数量、真实夹具摘要、互操作结果、资源和截图路径。性能阈值根据代表样本制定，不编造固定秒数或沿用 G0014 数量作为本期通过记录。
