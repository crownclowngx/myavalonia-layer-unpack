# G0010 浏览交互专项

## 默认流程

新建“浏览任务”，选择、拖入一个 ZIP，或粘贴路径点击重新加载。顶部显示归档名、来源、搜索和分页；中间是完整路径列表与复选框、可用大小，底部是摘要、输出位置和主要动作“提取所选”。密码/编码、条目详情/限制默认折叠；加密内容或补密失败就地展开密码。

普通任务只需打开归档、勾选、检查可见输出位置、提取；默认一层，无需选择算法或进入高级设置。文件夹被勾选后选择全部后代，摘要明确包括搜索外的选择。双向三态复选框展示父目录的部分选中；点击一行只用于详情，不替代勾选。

一次只打开一个包。多文件拖入明确提示，不偷偷选第一个。大量条目采用每页 200 行和有限列表视口；上一页/下一页和搜索不会丢失选择。无匹配时保持已选数量，清除选择可以显式清空隐藏项。

## 状态与恢复

| 状态 | 页面行为 |
| --- | --- |
| 空/未加载 | 可输入或选择来源，提取禁用；不自动写入 |
| 读取中 | 真实读取字节/目录条目数，主要编辑冻结，取消可见 |
| 已加载 | 目录、大小、问题提示与选择；可搜索翻页，旧编码变化需重新加载 |
| 提取中 | 真实已处理项与展开字节，无虚构百分比；输入/输出/选择冻结，取消可见 |
| 成功 | 文件数、累计资源、打开最新结果；详情保留全部已提交路径 |
| 失败 | 归一化原因与下一步；补密保留选择，源变化清空选择并禁止使用旧快照 |
| 取消 | 等待真实清理后显示；旧成功产物保留，残留路径明确展示并阻止继续提取 |

一份所选内容作为一个原子产物，没有“选中文件的一半成功”；多次提取之间可以既有成功路径，又有本次失败。输出建议为源包旁的“提取结果”，手动指定后不因重新加载或换归档被覆盖。密码每次提取明确输入，开始即清空，避免下次任务隐式沿用。

## 全部解压入口

“全部解压…”在当前浏览页转入原 UnpackView 和独立 UnpackDocument，带入实际源路径及输出位置，默认一层；用户可在原页面打开递归并看到总层数，再显式开始。不会把浏览中筛选后的列表误当作全部输入，不传递浏览密码。

返回浏览只切换显示。再次进入仍在运行的解压任务时保留其输入和层数；空闲时按当前源重新准备任务。清空或关闭浏览页排空其承载解压任务。该实现遵守 SDK 3.3 公开边界，不依赖内部 Dock 导航，也不新增全局贡献。

## 尺寸与证据

固定主动作与输出区；列表和按需详情各有有限滚动视口。空提示行不占额外空间，隐含目录技术说明只放在详情。深/浅主题、900×760 与 640×520 的空、准备、成功、缺密状态生成 16 张截图；自动断言提取与成功入口在窗口内，以及 Tab 焦点可移动。

实际渲染证据位于 `artifacts/ui/G0010/`。这是 Avalonia Headless 自动界面测试，不代替原生选择器、真实拖放、125%/150%/200% DPI、屏幕阅读器或真实 Host 实机验收。这些项继续列为待验收。
