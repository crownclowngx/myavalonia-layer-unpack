# G0010 浏览与选择提取契约

## 目录与条目身份

一个 OpenAsync 产生一个全新 CatalogId。真实条目身份为 `(CatalogId, 中心目录序号)`，序号从 0 开始；为路径补出的目录使用负序号。重复名称、大小写冲突和文件/目录碰撞均保留独立行，不能用显示名称代替身份。重新加载、更换源或编码后必须重新选择。

目录显示完整包内路径、可用原大小/压缩大小、加密标记、属性及限制。缺少大小显示未知，不编造压缩率。浏览成功只说明已建立目录快照，不表示所有正文 CRC 或认证已验证。

GetPage 的搜索按完整路径进行不区分大小写的包含匹配，覆盖名称和目录；默认 200 行，最大 500 行，offset 从 0 开始；TotalMatches 是完整匹配行数，包括隐含目录。无内容搜索，不自动进入内部归档。目录上限内完整缓存元数据，UI 分页而非磁盘永久索引。

## 选择语义

文件选择表示具体序号。目录选择立即展开为当前快照中精确大小写路径及以 `路径/` 开头的全部真实后代；a 不包含 ab，也不自动合并 A。隐含目录只作为选择入口，不能将其负序号直接交给提取接口。显式空目录可以单独输出。

重复选择目录和子项以身份集合去重。取消子项后祖先呈部分选中；取消目录移除其全部后代。搜索、翻页和选中详情行不改变已选集合。数量分别统计真实文件与真实目录，隐含父目录不增加 ZIP 条目数；必要输出父目录由落盘阶段建立。Capture 复制集合，不随之后的交互变化。

选择内路径以既有 PathPolicy 归一化；完整预检比较每个目标及其父目录，跨平台均拒绝大小写冲突、同路径重复记录和文件/目录相撞。可以只选择同名记录之一，也可分别提取为两个编号产物；不能同时提取冲突集合后静默丢弃一项。选中不安全路径或链接时整次提取失败，未选中的问题项不妨碍提取独立安全项。

## 来源校验和成本

打开前后保存/验证完整 SHA-256 及最后写入时间；提取前按路径校验，再对真正用于解码的已打开句柄校验，提交前再次按路径校验。相同长度且恢复相同时间戳的内容替换也会失败。源变化或消失返回 InputChanged，当前会话失效；恢复原文件也不能重新激活旧选择，须 OpenAsync。

在 Windows 上只读句柄使用 FileShare.Read，阻止持有期间的写入和替换；在允许替换打开文件的平台上，按路径复验补充检测。此策略不是对恶意进程反复替换后恢复或文件系统非协作行为的绝对保证。

完整摘要会读取整个压缩源，打开默认有两次完整摘要，提取有三次完整摘要，另计目录和所选压缩流读取。因此不承诺打开只读中心目录字节，也不声称选择两个小文件就只读取这两个文件对应的原包范围。浏览不解码正文、展开字节为零，源读取成本公开可见。

## 默认资源上限

| 项目 | 默认值与计量方式 |
| --- | --- |
| 源文件 | 4 GiB，打开句柄后检查 |
| 会话读取 | 32 GiB；包装流实际返回字节累计，含摘要、中心目录、重复读取和失败尝试；不是物理设备 I/O 计数 |
| 中心目录空间 | 64 MiB 原始中心目录上限；另对路径字符串和目录行按每字符串 UTF-16 大小加 256 字节保守计量，包括祖先键；不是进程 RSS 硬上限 |
| 真实条目 | 每次打开最多 100,000 条，在引擎建数组前验证；每次提取访问的条目继续消耗展开账本的累计 100,000 条上限 |
| 显示行 | 最多 200,000 行，包含推导目录 |
| 路径深度 | 最多 128 个斜线分隔层次，超出时整个打开失败 |
| 展开内容 | 会话累计 10 GiB，单文件 2 GiB；共享既有固定缓冲与账本，在写出每块前检查 |
| 提取尝试 | 每会话最多 2,048 次，沿用 UnpackLimits，可由 Headless 调小 |
| 单次操作时间 | 5 分钟；打开和每次提取分别受限，超时与用户取消区分 |

重试、失败和取消不退还已记账字节与条目。读取的下一块预计越限时停止该块；展开沿用原政策，在写出前拒绝超限块，结果报告已记账量。预算耗尽或清理残留会阻止该会话再次提取。没有后台长驻临时索引、正文缓存或跨任务预算池。

元数据解析器通过受控流的同步/异步读、ReadByte 和 Seek 检查取消；应用层在摘要块、目录记录、条目及提交前也检查。有限元数据排序与索引建立可能短暂延后取消观察，不能将“发出取消”当作释放完成。

## 密码与格式

ZIP 目录可读时先显示，提取调用单独传入本次密码，支持范围见[矩阵](format-support-matrix.md)。密码不 Trim，长度上限 1024，GUI 空文本按未提供处理。无密码/错误密码/认证失败归一为 PasswordRequiredOrInvalid，不保存原始异常链。每次提取字段清空，后续再次提取需重新输入；秘密不进入请求、目录、结果、JSON、日志或其他任务。

旧 ZIP 默认 GB18030，UI 可选择 UTF-8、CP437、CP866；Unicode 标志遵循包内声明。更换编码须重新加载，提取沿用快照编码。ZipCrypto 密码编码复用 UTF-8。托管字符串释放引用不表示物理清零。

## 输出与取消

所选提取默认仅一层，保留原相对路径，内部 ZIP 等按普通文件输出。父目录由用户可见 OutputDirectory 指定；GUI 建议源包旁的“提取结果”，手动选择不被后续加载覆盖。

一份所选集合是一个事务：`.layer-unpack-随机ID` 暂存 → 全部所选记录验证 → 来源复验 → `{归档名}-所选` 不覆盖移动，冲突自动编号。没有部分文件成功提交；Files 仅在成功结果中列出实际文件，不包含目录。原包、已有成功产物和未选择内容保持原状。

取消/失败回滚整个未提交目录；输出父目录可能保留为空目录。清理失败返回本事务残留路径，后续提取阻断，页面要求检查。成功提交后的历史产物不因随后取消、清空或关闭被删除。DisposeAsync 幂等，取消并等待实际提取与清理退出，拒绝释放后的新工作；同会话并发提取被拒绝。

## Headless 示例

```csharp
await using var session = await new ArchiveBrowseService().OpenAsync(
    new BrowseRequest(sourcePath), cancellationToken: cancellationToken);
var page = session.Catalog.GetPage("资料", cancellationToken: cancellationToken);
var selection = new ArchiveSelection(session.Catalog);
foreach (var entry in page.Entries)
    selection.SetSelected(entry.Id, true);
var result = await session.ExtractAsync(selection.Capture(), outputDirectory,
    password: currentPassword, cancellationToken: cancellationToken);
```

变量由调用方提供。示例只选择当前返回页（目录会展开其全部后代），不代表把搜索的全部匹配页自动全选；需要更多页时显式迭代。独立目录/选择可供 R05/R06 复用，但本阶段不包含整理与转换。
