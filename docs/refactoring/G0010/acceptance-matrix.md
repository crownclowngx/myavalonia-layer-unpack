- 待实机：操作系统选择器、真实拖放、常用 DPI、辅助功能及真实 Host Dock/关闭。

- 未执行：Windows CI、Release、正式插件 ZIP、部署安装或发布门禁。用户要求在发布阶段再运行，不作为本次开发门禁。

没有用模拟内容替代格式证据；暂停/进度装饰器仅控制取消时间点，底层仍由真实 ZIP 提取和 OutputTransaction 清理。公开夹具密码遵循夹具 README，用户秘密不进入证据。
