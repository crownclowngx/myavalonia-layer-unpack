# G0010 / R04 计划：压缩包浏览与选择性提取

日期：2026-09-08。对应 [R04](../../roadmap/R04-archive-browsing-and-selection.md)。本阶段按用户要求直接实施，不使用 AIFLOW、Windows CI、Release、部署或发布门禁。

## 范围与顺序

1. Headless：ZIP 元数据目录、稳定条目身份、隐含父目录、分页搜索、显式后代集合。
2. 提取：目录与读取预算、原包 SHA-256 验证、一层提取、CRC/AES 验证、既有路径政策和不覆盖事务、关闭排空。
3. Plugin：第三个普通 Document、会话隔离、搜索与选择分离、补密、错误与结果入口；全部解压复用原页面。
4. Standalone：独立浏览 Scope、三页预览和关闭顺序。
5. 真实 ZIP 内容、冲突、密码、来源变化、资源、取消、UI 与 Scope 测试；完整本地 Debug 门禁；同步产品与专项文档。

## 设计约束

SOLID 优先：目录/选择规则、ZIP 适配、输出事务、会话生命周期和界面分责，依赖窄用例端口。只使用现有引擎，不增加通用归档框架或永久索引。中文注释说明原因及契约。

不把全量解压作为枚举实现。ZIP 中心目录可读时无需密码，内容提取每次明确提供当前会话密码。加密头与未声明格式不猜测支持，指向既有解压任务及支持矩阵。

## 完成标准

R04-AC01–08 都有实现或明确格式边界，并以真实文件清单/字节与故障测试验证。新流程不改变原批量解压。测试零失败、零跳过；门禁包含锁定还原、Debug 零警告构建、两项目测试、格式、文档路径。实机选择器、DPI 和真实 Host 未执行时据实列为待验收，历史 G 阶段证据不重写。
