# G0010 浏览与选择提取能力矩阵

本矩阵独立于[既有全量解压矩阵](../G0003/format-support-matrix.md)和[创建矩阵](../G0009/encryption-and-compression-matrix.md)。可解压不等于本期可浏览。

| 格式/变体 | 列目录 | 选择提取 | 证据与边界 |
| --- | --- | --- | --- |
| 单卷普通 ZIP，Stored/Deflate | 是 | 是 | BCL 生成中文、同名、空文件/目录、内部 ZIP；只输出所选清单，验证字节；坏 CRC 不提交 |
| ZIP64 单卷中心目录 | 是 | 是 | BCL 65,536 条、65,537 显示行；尾页及两个所选内容真实验证；不是超 4 GiB 输入承诺 |
| ZipCrypto | 目录可读先显示 | 本次补密后 | 上游公开 pkware 夹具，缺密、错密、补密、独立会话；UTF-8 密码编码 |
| WinZip AES AE-1/AE-2 | 目录可读先显示 | 本次补密后 | 上游两种 AES 夹具回读；Stored AES 包括零字节条目破坏认证尾部，必须失败 |
| 旧 ZIP 名称 | 是 | 沿用快照编码 | GB18030 自生成样本实际路径和字节验证；Unicode 标志优先，其他可选编码沿用既有解压映射 |
| 重复路径/大小写/文件目录冲突 | 全部保留并提示 | 单条可选，冲突集合拒绝 | 中心目录序号区分；输出编号、父目录大小写冲突、显式重复目录真实测试 |
| 路径逃逸/设备名/链接属性 | 行内问题可见 | 所选含问题时拒绝 | PathPolicy 与 ZIP 属性检查复用；独立安全项可单独提取 |
| 分卷 ZIP | 否 | 否 | 分卷标记测试明确返回 MissingVolume，不拼接猜测 |
| ZIP 加密中心目录/强加密、自解压前缀、附加目录记录 | 未声明支持 | 未声明支持 | 仅接受签名明确、可读且数量/长度一致的单卷中心目录；不提示输入密码后假装一定可浏览 |
| 7z / RAR（含加密头与固实） | 否 | 否 | 真实加密头和固实夹具拒绝浏览，提示转入原解压任务，密码在该任务内提供 |
| TAR / GZip / BZip2 / XZ | 否 | 否 | 顺序格式未接入；真实 tar.gz 拒绝浏览；原解压支持范围不变 |

ZIP 所选正文使用已验证的 SharpZipLib 1.4.2；目录预检只读取元数据，CRC/认证在读取所选流直到 EOF 时执行。完整源摘要读遍原包，已计入预算，不将随机定位能力宣传成只读取所选压缩数据。

扩展格式需补齐来源验证、条目身份、实际扫描/解码预算、取消、临时空间和真实清单/内容证据，再修改本矩阵。固实/顺序格式尤其不能沿用 ZIP 的正文随机读取假设。
