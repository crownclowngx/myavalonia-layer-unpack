## 预先明确的边界

- 分别模式以规范化、去重、父目录吸收子项后的顶层来源分组；普通嵌套目录不新增组。
- GUI 只给有限复选项；Headless 支持完整目录名、最后一段扩展名，拒绝规则表达式。
- 分别输出须位于所有来源目录之外，避免较早完成的包改变后续冻结清单；合并模式保留 R02 源内输出规则。
- 每个组复用独立单包事务；整批准备受总时限、总清单条目与源字节限制。不开放并发数。
- 只有有完整快照、无清理残留的读取/输出/超时失败可原地重试；取消、源变化和准备失败需新任务。
- 不新增依赖、历史、Workflow、7z 创建、分卷、每文件密码或密码管理器。原生选择器、拖放、DPI、桌面接收工具与 Host 验收分别保留待验项。
