## 范围和遗留

分别输出要求位于全部源目录之外，避免批次自有产物改变后续组快照；合并源内输出保持 R02 规则。排除计数是规则命中项，命中目录以一项表示其全部后代，不声称已枚举排除树中文件数量。

AES“仅打包”为 Deflate 0 不压缩块，规避 SharpCompress 0.50.4 非空 Stored AES 长度问题。独立互操作使用中央目录 API；顺序 ReaderFactory 的零字节 AES 清单问题列为受限。修复现有解压 Memory 重载绕开 Stored AES 认证的问题，保留零字节与非空真实损坏样本。

原生选择器、拖放、多 DPI、桌面接收工具和真实 Host 仍待验收。没有使用 AIFLOW、Windows CI、Release、正式插件 ZIP、部署、安装或发布门禁；未升级依赖。后续发布时恢复发布门禁，不标记全环境封板。
