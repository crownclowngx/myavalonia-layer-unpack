# G0009 交互专项

日期：2026-09-08。页面继续使用一个滚动内容区和固定底部操作，复用压缩 Document 身份。

## 默认和按需展开

默认展示添加文件/文件夹、输入摘要、压缩包名称、输出位置、开始；无必选模式、算法或密码。添加输入仍会只读准备，不创建目标目录。普通合包不增加点击。更多选项默认折叠，提供分别打包、四级压缩偏好、有限排除项及 AES-256 开关。

分别模式隐藏没有意义的单包名称输入。排除选项为 `.tmp/.bak`、`.log`、`bin/obj`、`.git`、`node_modules`，全部默认关闭，明确类型/目录匹配方式。点击预览后自动展开来源到目标映射、包内路径和排除原因。若开始时尚未审阅分别分组、排除或冲突映射，先显示新清单，再次开始才执行。

加密开关旁说明接收方工具支持要求和名称可见性。开启后显示密码和再次输入，默认遮蔽；可临时显示，两次内容完全相同才执行。预览不要求填写密码。执行使用冻结秘密，编辑当前表单不能改写原批次重试。

## 运行、完成与恢复

| 状态 | 呈现和可操作入口 |
| --- | --- |
| 准备/运行 | 禁用输入及高级参数；当前组序号、当前项和当前组进度；固定取消按钮 |
| 成功 | 先显示成功数、真实源字节/ZIP 字节、每组实际路径和打开输出文件夹 |
| 部分失败 | 保留成功路径；逐组显示原因、重试资格和下一步，不用批次失败覆盖成功产物 |
| 可恢复失败 | “重试可恢复失败组”沿用原计划、目标和密码，不再创建成功包 |
| 来源变化/取消/准备失败 | “重新准备未完成项”只建立未完成来源的新清单，先前成功路径继续可见；确认后开始，加密需重新输入密码 |
| 全部排除 | 显示无可打包内容/已跳过，成功数为零，不出现虚假产物入口 |
| 取消/关闭 | 取消后等待实际写入与清理；关闭排空后台和会话，清空密码，迟到进度失效 |

清空任务恢复所有默认选项、清除当前呈现和会话内保留路径，释放密码；成功文件及来源不删除。普通再次开始属于新的显式操作；若只想恢复未完成项，使用对应按钮避免重建成功包。

## 自动化与实机边界

`PackBatchDocumentTests` 覆盖默认合包、预览审阅、排空跳过、重复密码、两个压缩页加一个解压页隔离、序列化不含秘密、冻结参数重试、来源变化后的新任务、关闭清理与迟到回调。

900×760、640×520，深浅主题，默认/更多选项展开/部分失败三状态，共 12 张图输出到 `artifacts/ui/G0009/`。断言密码字符、Tab 焦点、固定开始按钮和失败时成功产物入口；实际查看记录见[结果](result.md)。

Headless 渲染不是原生文件选择器、拖放、DPI 或 Host 验收。本轮未执行 125%/150%/200% DPI、接收方桌面工具、正式插件安装或发布门禁；后续按发布阶段补齐。
