# R08：工作流与插件协作

> 状态：已实现最小两个无密码动作和真实本地跨插件流程；加密秘密通道、可选动作及原生宿主验收另列后续 · 实施映射：[G0014](../refactoring/G0014/result.md)
>
> 前置：R02 及当前解压 Headless；其他动作取决于对应 R 阶段已验证能力。
>
> 产出：通过宿主公开 Workflow 契约复用归档操作，GUI 保持快速单任务体验。

## 1. 用户目标与代表流程

自动化用于重复或跨插件任务，例如：

- 下载完成 → 解压指定层数 → 将成功产物交给后续文件处理。
- 图片处理完成 → 按文件夹打包 → 返回各个压缩包路径。
- 解压 → 提取 PDF → 按来源整理 → 生成交付 ZIP。

本阶段提供可组合动作和真实集成样例。下载、图片处理等其他插件的能力应在开工时核实，不将示例流程视为它们已经具备所需接口。

## 2. 最小交付与扩展顺序

先交付“解压”“创建归档”两个动作及一个真实跨插件流程，再按实际需求开放枚举、选择提取、整理、检查或复合重打包动作。没有前置实现的动作不注册占位能力。

| 动作类型 | 普通输入 | 主要输出 |
| --- | --- | --- |
| 解压 | 来源路径、输出位置、总层数等业务参数 | 已提交产物、来源关系、部分失败和诊断 |
| 创建 | 明确文件清单、目标、分组、已支持格式 | 已提交归档及各组结果 |
| 后续可选动作 | 枚举、筛选、整理、检查的已验证契约 | 条目清单、目标映射或检查结果 |

GUI 不新增一个完整 Workflow 编辑器，不把调度、资源预算和跨插件依赖放进普通压缩页。需要构建多步骤流程时使用已有工作流产品入口。

## 3. 跨插件契约

- 只通过当时公开的 SDK / Workflow 契约调用，不共享插件私有 CLR 类型，不直接解析另一插件容器。
- 对外传递可验证的输入和结构化结果，不暴露可变会话、引擎实例或临时内部路径作为稳定 API。
- 动作实际执行仍调用同一 Headless 用例，层数、分组、命名和输出语义与 GUI 一致。
- 声明动作标识、参数与结果版本，新增字段和行为变化有兼容策略。
- 结果区分成功产物、失败项、正常跳过与取消；下游只消费显式提供的成功输出。
- 输入路径来自调用方也要执行同等验证，不假设上游提供的路径永远可用或已通过本次检查。

现有[Workflow 边界文档](../workflow-actions.md)已记录 G0014 两个无密码 Provider；注册测试和质量基线同步更新。V1/G0001–G0013 零贡献记录保持为历史事实。

## 4. 密码、重试与生命周期

普通参数可能被工作流保存，因此密码通过经验证的秘密通道或引用传递，不把候选数组或目标密码放进可记录 JSON、节点配置、重试日志和错误链。

若宿主尚无合适的秘密能力，可以先交付无密码动作，并明确暂不开放加密参数；记录剩余子范围，不能以明文普通参数绕过缺口。

工作流取消应传递到实际读取、整理和写入。关闭责任归本次动作的生命周期，不能把 GUI 关闭规则直接套到独立工作流运行；不在插件中另建隐藏后台队列。

非交互调用缺密时返回结构化结果，不弹出页面或无限等待。重试策略应由动作与调度平台共同明确：命名自动编号本身不等于幂等，重新运行不能无说明地产生多份看似相同交付物。

每个动作说明独立调用、失败重试与重复执行时的输出政策。一个复合流程的中间文件由明确的拥有者清理，下游失败不自动删除已交付给用户的成功产物。

## 5. 工程切入与阶段交付物

先核对宿主和 `myavalonia-workflow-studio` 的实际接口、动作发现、参数持久化、秘密处理、取消和结果传递行为，再编写适配计划。

交付物包括：最小动作目录、输入输出与版本契约、秘密传递与脱敏验证、生命周期和重复执行策略、跨 ALC 测试、一个真实集成流程，以及使用说明。

CLI / MCP 不与 Workflow 默认捆绑。如果存在明确调用需求，再复用这些契约另生成执行计划，避免一次维护多个未使用入口。

## 6. 验收场景

| 编号 | 场景 | 阶段出口要求 |
| --- | --- | --- |
| R08-AC01 | 无 UI 调用解压与创建 | 与 GUI 相同输入得到等价的内容、路径政策和终态 |
| R08-AC02 | 真实上游产物传给归档动作 | 通过公开契约调用，来源与结果可追踪，无私有类型穿越 |
| R08-AC03 | 一部分输入失败 | 下游只拿到明确成功清单，部分失败不伪装整批成功 |
| R08-AC04 | 无密码通道或需要密码 | 返回准确能力或缺密结果，无 GUI 弹窗，无明文参数持久化 |
| R08-AC05 | 有秘密通道的加密动作 | 只在选入该子范围时验证；日志、配置、结果均不含密码 |
| R08-AC06 | 流程取消与宿主退出 | 实际工作停止并清理自有临时内容，完成状态可信 |
| R08-AC07 | 同一动作重试或流程重复运行 | 输出与幂等政策一致，无隐式覆盖或无法解释的重复包 |
| R08-AC08 | 多个并发调用及 GUI 同时使用 | 可变状态与秘密隔离，输出命名冲突按契约处理 |
| R08-AC09 | 重新打开普通压缩／解压页面 | 没有新增必须理解的工作流配置，默认快速路径保持 |

## 7. 非目标与阶段出口

不包含新工作流编辑器、插件私有后台服务、自动目录监听、任务历史库、定时调度器、全局密码共享或对其他插件的大范围重构。

完成标准是计划选定的动作和真实流程有实际环境证据。若只完成无密码或最小两个动作，按该子范围记录，不把所有候选动作、CLI / MCP 或加密流程标成已完成。
