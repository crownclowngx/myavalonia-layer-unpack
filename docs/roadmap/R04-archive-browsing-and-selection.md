# R04：压缩包浏览与选择性提取

> 状态：已实施／完整本地门禁及 292 项测试通过，部分原生交互待验收 · 实施映射：G0010
>
> 前置：R01 与已有解压能力；推荐在 R03 后推进，技术上不依赖加密创建。
>
> 产出：查看一个归档中的内容，按选择提取所需文件。

当前 ZIP/ZIP64 声明范围见[G0010 结果](../refactoring/G0010/result.md)、[浏览契约](../refactoring/G0010/browsing-contract.md)、[能力矩阵](../refactoring/G0010/format-support-matrix.md)和[验收矩阵](../refactoring/G0010/acceptance-matrix.md)。入口为新建浏览 Document；全部解压在当前页承载原解压任务。其他格式、加密中心目录与分卷不声明浏览支持，源摘要完整读取计量，实机与发布边界单独记录。

## 1. 用户目标与主流程

用户打开一个压缩包，看到目录和文件，按名称搜索，选中文件或文件夹，点击“提取所选”，得到对应内容。快速批量解压继续由原解压任务承担。

浏览入口可以来自新建浏览任务、输入项或结果项的“查看内容”。不为此默认接管系统文件关联，也不要求所有解压任务先浏览再开始。

## 2. 交付范围与界面

| 区域 | 目标内容 |
| --- | --- |
| 顶部 | 当前归档名称、搜索、必要时输入密码 |
| 主区域 | 目录与文件列表，名称和可用的大小信息，选择状态 |
| 操作区 | 提取所选、全部解压的轻量入口、输出位置 |
| 按需详情 | 路径、格式、条目属性、已知限制与错误 |

先交付 ZIP 的列目录、搜索、选择、提取闭环；其他格式按独立能力矩阵逐项接入。不把“可解压”直接等同于“可快速浏览和随机提取”。

搜索首版只针对当前归档内可枚举的名称和路径，不搜索文件内容，不自动打开内部压缩包。列表可分批呈现或虚拟化，打开大量条目时保持响应和取消能力。

## 3. 浏览与提取规则

- 列目录阶段原则上不把内容展开到用户输出目录；格式要求的扫描、解码和临时资源需要计量与清理。
- 加密头导致不能枚举时，就地要求本会话密码；只加密内容时可先显示可读目录，提取时再使用密码。
- 目录选择代表明确的后代集合；搜索仅改变显示结果，不应悄悄改变已选集合。
- 以稳定条目身份记录选择；重复路径、大小写冲突等不能仅靠显示名称消歧。
- 选择性提取保留包内相对路径，避免同名文件被扁平化覆盖；仍使用现有路径检查与不覆盖输出原则。
- 浏览和提取之间校验来源变化；原包被替换时失效旧选择并要求重新加载。
- 固实或顺序读取格式即使只选少量文件也可能需要处理前面的数据，不能承诺只读取被选文件。实际读取和展开量均计入预算。

首版提取所选默认一层，不将选择与递归混成不明确规则。需要递归全部解压时，转入原解压任务并显示对应输入和层数。

## 4. 工程切入与阶段交付物

Headless 增加枚举条目、选择描述和选择提取用例。可以复用引擎与落盘政策，但不以完整解压到隐蔽目录作为所有浏览操作的默认实现。

Plugin 增加或承载独立浏览 Document，分配稳定身份；注册数量、Scope 生命周期和 Standalone 预览随之更新。浏览会话缓存仅用于当前任务，不形成永久归档索引。

详细计划交付：条目身份与分页模型、选择语义、来源变化检测、各格式浏览能力、密码作用域、取消与临时空间契约，以及列表和错误状态方案。

## 5. 验收场景

| 编号 | 场景 | 阶段出口要求 |
| --- | --- | --- |
| R04-AC01 | 普通 ZIP 浏览并提取两个文件 | 列表与归档一致，只输出被选内容及必要目录 |
| R04-AC02 | 搜索后选择目录与子项 | 选择数量、后代范围和最终文件清单一致 |
| R04-AC03 | 不同目录下同名文件 | 保持相对路径，内容不覆盖、不混淆 |
| R04-AC04 | 重复条目或大小写冲突 | 浏览状态可解释，提取不会静默丢弃或覆盖 |
| R04-AC05 | 加密头／加密内容 | 根据实际支持范围就地补密，无跨任务秘密继承 |
| R04-AC06 | 浏览后源归档被替换 | 旧选择不可直接执行，提示重新加载 |
| R04-AC07 | 大量条目或顺序／固实格式 | 页面可响应、可取消，资源按实际工作量计量 |
| R04-AC08 | 提取中取消或关闭浏览页 | 未提交输出清理，已提交产物与会话释放符合契约 |

## 6. 非目标与阶段出口

不包含包内修改、拖回归档追加、全文搜索、媒体预览、无限嵌套浏览或系统文件关联。底层能力不支持的操作，界面说明原因或引导使用已验证的全部解压路径。

完成标准是声明格式的浏览与选择性提取有真实清单和内容证据，原解压操作不被强制增加浏览步骤。R05 可复用条目选择语义，R06 可复用枚举与来源验证。
